HyperBricks + HTMX 4.0.0

Overview

Three server-rendered pages demonstrating section menus, templates and fragment responses.

Routing

Section-based navigation

Each page declares section: scaffold_navigation and an index. The menu component discovers the pages, orders the links and sets aria-current="page" on the active item.

section: scaffold_navigation
index: 20

Page updates

Canonical page requests

Menu links request the full page route. HTMX selects its content and replaces the menu out of band, so the active link updates with the page.

The URL and document title follow navigation. Direct visits and reloads return complete pages.

Templates

Data to HTML

The Templates page demonstrates an inline template, a resource-file value, an environment fallback and an ordered tree of components.

Fragments

Targeted replacement

The Fragments page requests /hello-status and replaces only its response panel. Repeat the request to verify that the replacement keeps the same target ID.
