Resolved disk path

This is the result of path: {base: static, path: thefile.txt}, not an HTML URL.

base: module starts at the selected module; base: root starts at the CLI working directory. Neither changes /static/.

On the nested page, a relative URL such as static/thefile.txt would request /nested/static/thefile.txt. Use the leading slash.
